Security
Wary is a small static website. It has no accounts, no cookies, no database and no server code that visitors can reach. It is rebuilt by GitHub Actions from official public data.
Reporting a problem
If you think you have found a security or privacy problem (for example something that could make the site show false information, contact a third party unexpectedly, or expose a secret), please email the contact address shown in the About section of the website, or at `/.well-known/security.txt`. Please do not open a public issue with the details.
Include what you saw, where, and how to reproduce it. You will get a reply as soon as the owner can manage. This is an independent, non-commercial project run by one person, so please be patient.
What is and is not in scope
In scope: the website, its build and publishing workflow, and anything that could cause the site to state something false or leak visitor data.
Not in scope: attacks on GitHub, GitHub Pages, GOV.UK, MI5 or any other third-party service.
What the site promises (and a test checks)
No cookies, no ads, no analytics, no accounts.
A visitor's household details stay in their own browser. If they add the first half of a postcode, their own browser asks postcodes.io and the Environment Agency about that area directly.
The page's security policy allows connections only to the site itself and those two public services.
